### 4.1 短期（规划中）

- [ ] 发布 `1.0.0`：固化配置结构，启用 Git Tag 与 SemVer 兼容性承诺。
- [ ] 补充 `RelativeTimeGenerator`（基于查账时间的相对时间生成）。
